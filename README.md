# DESK — Trading journal

Personal paper journal. Trades stay in this browser. No login. No paid APIs.

## Open on your computer

1. Unzip this folder.
2. Double-click `index.html`.
3. Use Chrome or Edge.

Typing a fill always works. Screenshot reading needs the site hosted (GitHub Pages below). You can also paste order text.

## Put it on GitHub Pages

1. Create a GitHub repository (public is fine).
2. Upload every file in this folder to the **root** of the repo
   (`index.html` should be visible at the top, not inside another folder).
3. Repo → Settings → Pages → Build and deployment
4. Source: **Deploy from a branch**
5. Branch: `main` (or `master`), folder: `/ (root)`
6. Save. After a minute the site URL is:
   `https://YOURUSER.github.io/REPONAME/`

## Backup

Import / Export → Export JSON after a session.

A public GitHub page does **not** contain your trades. Keep the JSON file yourself. On a new phone, open the site and import that file.

## Notes

- Starting cash is $10,000. Size default is $900.
- MAIN and TEMP watchlists are already seeded.
- Closed trades need an exit reason and a short review note.
